Liburu is a local-first macOS desktop app for browsing, editing, and organizing Markdown across journals, notes, and Git-backed folders. No account. No sync. No internet required.

Features

Everything you need.
Nothing you don't.

Built for developers and writers who want to own their notes without giving them to a cloud service.

Open any folder

Point Liburu at any local directory and start reading immediately. No import, no migration, no lock-in.

Git-aware

See branch info, file statuses, and per-file commit history without opening a terminal.

Full-text search

Search across all files in your space instantly. Path matches and content matches, side by side.

Edit and preview

Toggle between a rendered Markdown preview and a plain source editor. Autosave keeps you safe.

Journal entries

Create dated journal entries in one click, organized automatically into year/month folder structures.

Fully local

No account, no telemetry, no network requests. Your files stay on your machine, always.

Install

Up and running in seconds

1

Download the ZIP

Grab the latest release from GitHub Releases. Unzip it to find Liburu.app.

2

Move to Applications

Drag Liburu.app into your /Applications folder as you would any macOS app.

3

Right-click to open

On first launch, right-click the app and choose Open to get past the unsigned app warning.

Unsigned app notice: Liburu is not yet notarized. If macOS blocks it, run xattr -dr com.apple.quarantine /Applications/Liburu.app once in Terminal to clear the quarantine flag.
