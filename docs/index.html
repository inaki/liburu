Liburu

A local-first desktop app for reading and organizing Markdown across journals, notes, and Git-backed folders.

Download for macOS View Releases

What It Does

  • Browse Markdown spaces locally
  • Edit notes and journal entries
  • Read repos without leaving the desktop app

macOS Install

  • Download the ZIP from Releases
  • Move Liburu.app into Applications
  • Right-click and choose Open on first launch

Unsigned App

Liburu is currently distributed unsigned and not notarized, so macOS will show a first-run security warning.

If needed, run xattr -dr com.apple.quarantine /Applications/Liburu.app once after installing.
